COMANDOS ÚTEIS DE REFERÊNCIA:

- Build frontend: npm run build
- Build backend: docker build -f Dockerfile.backend .
- Ver logs backend: docker service logs credgestor_api --tail 100
- Ver logs frontend: docker service logs credgestor_site --tail 100
- Testar endpoint: curl -X POST https://credgestor.app.br/api/endpoint -H "Content-Type: application/json" -d '{}'
